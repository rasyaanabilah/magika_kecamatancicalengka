# MAGIKA
### Portal Magang Kecamatan Cicalengka

MAGIKA adalah aplikasi berbasis web yang dikembangkan untuk mendukung proses administrasi magang di Kecamatan Cicalengka, mulai dari pendaftaran, seleksi peserta, pengelolaan data, hingga pengumpulan laporan magang secara digital.

## Fitur Utama

- Registrasi & Login
- Pendaftaran Magang
- Verifikasi Pendaftar
- Kelola Status Pendaftaran
- Surat Kelulusan
- Upload Laporan Magang
- Dashboard Petugas, Camat, dan Peserta

## Teknologi

- **TypeScript**
- **React 18 (Vite)**
- **Tailwind CSS**
- **Lucide React**
- **Firebase Authentication**
- **Google Firebase Firestore**

## Instalasi

```bash
npm install
npm run dev
```

## Ringkasan

Aplikasi ini dikembangkan menggunakan **TypeScript** dengan **React (Vite)** sebagai framework frontend, **Tailwind CSS** untuk antarmuka pengguna, serta **Firebase Authentication** dan **Google Firebase Firestore** sebagai layanan autentikasi dan database real-time.
